# Evaluation protocol

- **Gate set:** `data/eval_real/` (MSST Type 1 + mixture.wav), ≥ 30 real drum-bus
  takes, never trained on. **It does not exist yet.** Until it does, no quality claim
  may be made anywhere (plan §0.1).
- **Development sets** (numbers are reported, never claimed): StemGMD test fold
  (synthetic, rendered from MIDI), ENST-Drums (research-use, eval-only, not obtained).
- **Metrics:** MSST's implementations (`sdr`, `l1_freq`, `bleedless`, `fullness`,
  `log_wmse`, `si_sdr`, ...) via the pinned submodule, so numbers are comparable to
  MVSEP-style tables; plus `onset_snr` = SDR restricted to ±5 ms around the reference
  onsets (GMD MIDI onsets when the set ships `onsets.json`, else detected onsets).
  SDR is capped at 100 dB (pred == ref). Stems whose reference is silent are not scored.
- **Groupings:** each model is scored at its native layout and at 4 stems (kick,
  snare, toms, cymbals) — the only layout B2 can be compared on.
- **Reports:** `kitsplit benchmark` writes `reports/<name>.md` + `.json` with git SHA,
  model sha256 + license, preset, dataset manifest sha256 (sha256 of every audio
  file), per-track rows and per-stem median/mean.
- **Gates (plan §9.5):** Q-1 shipped ≥ B1 on SDR and bleedless for kick/snare/toms on
  eval_real (hard fail); Q-2 cymbals reported only; Q-3 no stem drops > 0.3 dB vs
  last release; Q-4 `max|Σ − input| < 1e-6` on real files. Run with
  `pytest -m quality --real-data data/eval_real` on a GPU box.
- **Blind listening:** `eval/listening.py` (ABX folders) — **not implemented yet**.
- **README claims** are generated by `scripts/update_readme_claims.py` from
  `reports/latest.json` (an eval_real benchmark); `tests/unit/test_docs.py` fails if
  the README block differs from the generated one.
